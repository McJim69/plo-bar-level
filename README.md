## ✨ Overview
The **Barangay Level Organization** is a web application built with PHP/MySQL.  
It serves as the organizational structure system for local government units, designed to manage election‑related campaigns and voter functions.

---

## ⚙️ How It Works
This system acts as a **management tool** for campaigns:  
- Organizes positions and their functions.  
- Manages voter tagging and hierarchy.  
- Generates reports and summaries for administrators.
